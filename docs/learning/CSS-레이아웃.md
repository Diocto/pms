- 작성일: 2026-08-15
- 처음 마주친 맥락: 예약 화면의 검색 폼(가로 6칸)과 본문+사이드 카드(2단) 배치를 짜면서 (`frontend/app/globals.css`, 각 page.tsx)

## 한 줄 정의

flex는 **한 줄**(가로나 세로 하나의 축)에 요소들을 배열하는 도구이고, grid는 **표처럼 행과 열**을 먼저 선언하고 요소를 채우는 도구다.

## 왜 존재하는가

CSS의 기본 배치는 "위에서 아래로 쌓기"뿐이다. "버튼을 오른쪽 끝에", "폼을 6칸으로", "남는 공간을 이 칸이 다 가져가게" 같은 요구는 기본 배치로 안 되고, 예전에는 온갖 편법(float, 음수 마진)으로 흉내 냈다. flex와 grid는 이걸 선언으로 해결한다: **부모가 배치 규칙을 선언하면 자식들이 그 규칙대로 놓인다.** 배치의 주체는 언제나 부모라는 것이 가장 중요한 원칙이다.

## 어떻게 동작하는가

**flex — 한 줄의 축을 다룬다.**

```css
.between {              /* 이 프로젝트에서 가장 많이 쓴 패턴 */
  display: flex;        /* 자식들을 가로 한 줄로 */
  align-items: center;  /* 세로(교차축) 가운데 정렬 */
  justify-content: space-between; /* 가로(주축): 양 끝으로 밀고 사이를 벌린다 */
  gap: 16px;            /* 자식 사이 간격 — 마진 대신 이걸 쓴다 */
}
.grow { flex: 1; }      /* 이 자식이 남는 공간을 전부 가져간다 */
```

축 두 개만 기억하면 된다: 주축(justify-content가 다룸)과 교차축(align-items가 다룸).

**grid — 행과 열의 표를 먼저 그린다.**

```css
/* 검색 폼: 호텔 칸을 1.5배 넓게, 나머지는 비율대로, 버튼은 내용만큼 */
.search-form {
  display: grid;
  grid-template-columns: 1.5fr 1fr 1fr 0.7fr 0.7fr auto;
  gap: 12px;
  align-items: end;     /* 라벨 높이가 달라도 입력칸 아랫변을 맞춘다 */
}
```

`fr`는 "남는 공간의 비율"이라는 단위다. `auto`는 내용 크기만큼. 열 선언 하나로 여섯 입력칸의 폭 배분이 끝난다.

## 언제 무엇을 쓰는가

| 상황 | 도구 | 이 프로젝트의 실례 |
|---|---|---|
| 제목 왼쪽 + 버튼 오른쪽 | flex (between) | 결과 카드의 이름/가격 배치 |
| 아이템들을 세로로 간격 있게 쌓기 | flex 세로 (stack) | 검색 결과 목록 |
| 폭 배분이 정해진 폼·2단 레이아웃 | grid | 검색 폼 6칸, 주문서 본문+요금 카드 |
| 요소 하나의 위치 미세 조정 | 둘 다 아님 | padding·margin의 일이다 |

경계가 애매하면: **칸의 구조가 먼저 떠오르면 grid, 줄 세우기가 먼저 떠오르면 flex.**

## 흔한 오해와 함정

- 자식 각각에 마진을 줘서 간격을 만드는 것 — 마진은 상쇄·중복이 생긴다. **간격은 부모의 `gap`으로** 만드는 게 예측 가능하다. 이 프로젝트의 CSS에는 형제 간 마진이 거의 없다.
- 2단 레이아웃을 좁은 화면에서 그대로 두는 것 — grid는 미디어 쿼리에서 `grid-template-columns: 1fr` 한 줄로 세로 쌓기로 바뀐다. 주문서·상세 화면이 이 방식이다.
- flex 자식이 넘칠 때: 기본값 `min-width: auto` 때문에 줄어들지 않는다. `min-width: 0`(이 프로젝트의 `.grow`)이 해법이다.

## 이 프로젝트에서는

`frontend/app/globals.css`의 `.stack`(세로 flex) `.inline`(가로 flex) `.between`(양끝 flex) 세 클래스가 배치의 90%를 담당한다. 표 같은 구조(검색 폼, 본문+사이드)만 grid다. 스타일 라이브러리 없이(D2) 이 정도 규칙으로 세 화면이 전부 조립된다는 것 자체가 이 노트의 결론이다 — **레이아웃 도구는 두 개뿐이고, 고르는 기준은 구조의 모양이다.**
