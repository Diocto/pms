## 이 목록을 만들 때 지킨 것

- **완료를 판정할 수 있는 단위로 쪼갰다.** 화면 하나 = Task 하나이고, 완료 기준이 가짜 응답 전환으로 즉시 확인된다
- **완료 기준을 관찰 가능한 것으로 썼다.** "멱등성이 지켜진다"가 아니라 "세 재시도 경로의 키가 같다(개발자 도구 확인)"
- **순서에 이유가 있다 — 절단 내성이 기준이다.** F05는 절단 1순위라, 3화면을 병렬로 절반씩 만들면 잘리는 순간 셋 다 미완이다. T1·T2(공통 기반) 뒤에 **화면을 하나씩 끝까지** 끝낸다(T3→T4→T5). T3에서 잘리면 "검색은 동작한다"가, T4에서 잘리면 "검색과 주문서는 동작한다"가 남는다. 교육 노트 본문(T7·T8)은 판단이 실제로 생긴 뒤에 쓰므로 화면 뒤에 온다 — 단, 판단이 생기는 시점에 메모는 그때그때 남긴다
- **하나가 반나절을 넘지 않는다.** 가장 큰 T4(409 흐름)도 시안에 상태·문구·재시도 규칙이 전부 확정돼 있어 구현만 남았다
