## 이 목록을 만들 때 지킨 것

- **완료를 판정할 수 있는 단위로 쪼갰다.** T11이 커 보이지만 "시나리오 하나 = reset → k6 → verify 종료 코드 0"으로 시나리오마다 판정된다. 소요는 필수 구간 합계 2시간 50분으로 산정돼 있다 (`scenarios.md` §5)
- **완료 기준을 관찰 가능한 것으로 썼다.** 전부 종료 코드·카운트·문서의 빈칸 여부다
- **순서에 이유가 있다.** T9(대조)가 T10~의 전제다 — 대조 없이 실행하면 Enum 표기 하나로 검증 전체가 조용히 무력화된다. T10(검증기 검증)이 T11의 전제다 — 검증기가 고장 나 있으면 뒤의 모든 결과가 무의미하다. T13의 selftest 2차는 이력이 생긴 뒤에만 가능해서 그 자리다
- **하나가 반나절을 넘지 않는다.** 가장 긴 T11이 약 1시간 20분, T12가 50분이다
